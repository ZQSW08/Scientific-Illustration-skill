# Figure Review Checklist

## Scientific integrity
- [ ] 数据没有被平滑到改变结论。
- [ ] 没有隐藏失败点。
- [ ] normalization 有说明。
- [ ] errorbar 定义清楚。
- [ ] 对比坐标范围公平。

## Argument
- [ ] 这张图只回答一个主问题。
- [ ] caption 能说出该图支持哪个 claim。
- [ ] 中间机制图真的展示了机制变量。

## Layout
- [ ] panel 顺序与阅读逻辑一致。
- [ ] proposed 方法视觉优先级最高但不过度夸张。
- [ ] 留白充分。
- [ ] legend 不挡数据。
- [ ] panel label 位置一致。

## Visual encoding
- [ ] 同一方法颜色一致。
- [ ] 色盲可区分。
- [ ] 黑白仍能辨认。
- [ ] continuous data 没有使用误导性 rainbow。
- [ ] 0-centered field 使用合适 diverging map。

## Technical
- [ ] 单位完整。
- [ ] 字号按最终版面可读。
- [ ] 线宽不会在导出后消失。
- [ ] 图片分辨率足够。
- [ ] 矢量元素优先矢量导出。
